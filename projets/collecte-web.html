Pas de dépôt public pour ce projet.

L'objectif

Extraire des données sur des sites dynamiques et les enregistrer dans un fichier exploitable.

Les fonctionnalités

  • Navigateur piloté. Playwright ouvre un vrai navigateur et charge la page comme un visiteur.
  • Attente des éléments. Le script attend que les éléments apparaissent avant de les lire.
  • Sélecteurs CSS. Les données sont repérées dans la page avec des sélecteurs CSS.
  • Export JSON. Les résultats sont enregistrés dans un fichier JSON.

Le pipeline

Mon rôle

Projet personnel, réalisé seul. Il n'a pas de dépôt public et les sites collectés ne sont pas cités.

La difficulté

Sur les sites dynamiques, le contenu n'existe pas encore quand la page arrive, il faut attendre que les éléments apparaissent.

La solution

C'est pour ça que j'ai utilisé Playwright, qui pilote un vrai navigateur.
